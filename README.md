# Agent 额度

统一监控 **Codex** 与 **Antigravity** 双引擎额度的 macOS 菜单栏与桌面悬浮卡片工具。

## 核心设计

- **钛金属双引擎仪表（Titanium Dual-Cockpit）**：暗钛磨砂底面搭配双引擎专属识别色——Codex 为翠玉青（`#10B981`）、Antigravity 为星际电光蓝（`#3B82F6`），任一引擎余量低于 30% / 15% 时自动转为琥珀金 / 珊瑚红预警。
- **工作节奏刻度**：5 小时进度条内嵌 20% 分段刻度与**时间基准竖线**，配合 `剩 XhXXm` 倒计时与重置时刻，直观对比消耗速度与窗口剩余时间。
- **独立并发采集**：`codex app-server` 与 `agy -p /usage` 在独立后台队列并发拉取，谁先返回先更新谁，互不阻塞。默认 **60 秒**刷新一次，可在菜单栏或右键菜单切换 `1 分钟 / 3 分钟`。
- **统一菜单栏入口**：状态栏常驻 `C XX · G XX`，点击紧贴菜单栏展开双引擎详情与 Claude/GPT、Argon 余量。

## 快捷键与操作

- **⌃⌥Q**：全局显示 / 隐藏桌面卡片
- **拖动卡片**：100% 自由跟手拖动，自动限制在屏幕可视区内
- **右键卡片**：显示/隐藏、置顶、贴靠角落（四角平滑归位）、切换刷新频率（1m / 3m）、切换费用币种（`$` / `¥`）、立即刷新、退出

## 下载与安装（同事直接使用）

1. 前往本仓库 **Releases** 页面下载 `Agent-Quota-Card.zip` 并解压；
2. 将 `Agent 额度.app` 拖入 `/Applications`（应用程序）目录即可运行（首次打开如遇提示，在「系统设置 → 隐私与安全性」点击仍要打开）。
3. 需本机已登录并可用 `codex` 或 `agy` CLI；如本机运行了 TokenLens（`127.0.0.1:7777`），卡片底部会自动显示今日用量与费用。

## 从源码构建

```bash
./app/Scripts/build-app.sh
```

双击 `安装.command` 安装到 `/Applications/Agent 额度.app` 并启动。
